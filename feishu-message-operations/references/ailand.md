# AI Land 项目路由

仅当实际操作或修改 AI Land 项目的批量消息运营能力时使用本路由。普通 AI Land 任务和单张本人测试不加载消息运营详细文档。

仅使用 AI Land 已配置的飞书应用作为独立任务的查询或发送主体，不等于操作项目运营页面。用户指定的独立官方 API 流程使用技能通用流程，并遵守实际适用的凭证与项目规则；不要因应用名称相同额外引入页面确认或部署改造。

按需读取当前事实源：

1. `AGENTS.md` 的消息运营规则；
2. `docs/message-push-operation-system.md` 的批量推送标准；
3. `docs/operator-runbook.md` 的消息运营预览与受控正式发送；
4. 当前页面、API、审计和发送实现。

项目文档和代码是当前项目行为的事实源；用户与上级指令仍优先。不要在本参考复制应用 ID、凭证、人员名单、活动状态或部署事实。

文档缺失时检查当前 AGENTS、运行手册及实现是否提供替代流程，不根据旧会话猜测能力。只有当前项目要求的发送门禁确实无法核实时，暂停对应正式发送并说明具体缺失；不要仅凭一个文件名缺失阻断已明确授权的独立 API 操作。
